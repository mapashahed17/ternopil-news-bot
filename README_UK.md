# News Ternopil Bot

Telegram RSS-агрегатор для каналу `@ternopil_live_news`.

## Перед запуском
1. У Telegram відкрий налаштування каналу → Адміністратори → додай `@NewsTernopilBot`.
2. Дозволь боту публікувати повідомлення.
3. На комп'ютері встанови Python 3.11 або новіший.
4. Розпакуй архів і відкрий термінал у цій папці.
5. Створи віртуальне середовище (необов'язково, але рекомендовано):
   - Windows: `py -m venv .venv` і `.venv\Scripts\activate`
   - macOS/Linux: `python3 -m venv .venv` і `source .venv/bin/activate`
6. Встанови залежності: `pip install -r requirements.txt`
7. Задай змінну `TELEGRAM_BOT_TOKEN` зі значенням, отриманим у BotFather.
   Не надсилай токен у чат і не публікуй його в коді.
   - Windows PowerShell: `$env:TELEGRAM_BOT_TOKEN="ТВІЙ_ТОКЕН"`
   - macOS/Linux: `export TELEGRAM_BOT_TOKEN="ТВІЙ_ТОКЕН"`
8. Запусти: `python main.py`

Канал за замовчуванням — `@ternopil_live_news`. Якщо перший запуск успішний, бот позначить наявні публікації як переглянуті, щоб не засипати канал старими новинами. Далі перевірятиме RSS кожні 5 хвилин.

## Джерела
За замовчуванням підключено `https://ternopil.cx.ua/feed`. Додавай інші перевірені RSS-стрічки до списку `FEEDS` у `main.py` у форматі:
`("Назва джерела", "https://сайт.example/feed")`

Не обходь авторизацію, блокування чи технічні обмеження сайтів. Публікуй заголовок, короткий опис і посилання на оригінал, а не повні статті. Перевір правила використання контенту кожного джерела.

## Перевірка
- Якщо бот не публікує, перевір, що він є адміністратором каналу з правом публікації.
- Перевір токен і повідомлення про помилки в терміналі.
- Під час першого запуску бот не публікує старі записи; він чекає на нові.
- Для цілодобової роботи потрібно запустити процес на хостингу/сервері, який не вимикається. Закриття термінала зупиняє бота.
- Файл `seen_items.json` зберігає вже оброблені записи. Не видаляй його без потреби, інакше бот може повторно обробляти новини.
